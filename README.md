# Coupling va Cohesion: monolit modulni bo'lish

"Dasturiy tizimlarni loyihalash" fanidan 2-laboratoriya ishi (TDTU).
Bitta `process_student()` funksiyasi to'rtta funksional modulga ajratilgan.

| Modul | Mas'uliyati |
|-------|-------------|
| `validator.py` | Baholarni tekshirish |
| `storage.py` | Faylga yozish |
| `calculator.py` | O'rtacha ballni hisoblash |
| `reporter.py` | Natijani chiqarish |
| `main.py` | Modullarni ketma-ket chaqirish |

## Ishga tushirish

```bash
python main.py
```
